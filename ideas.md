# Ideas

# LearnAnything

Simple project that would allow you to register "things"

You would then be able to track your progress on that thing

Streaks would be measured for daily activity

You can add notes about things you have learned

You can add links to resources like youtube videos regarding learning

Can configure notifications to be sent if you haven't done a certain thing

Maybe give access to an AI agent that provides a roadmap for learning or gives advice for learning

# Application Health Monitor

Would allow applications to be registered and monitored from a dashboard.

Would allow API requests to be sent from the dashboard

Uptime monitoring

Health Reports

KPI configuration

# Budget Monitor

Uses Plaid integration to track transactions, subscriptions, etc

Categorizes transactions and tracks it against your allotted monthly budget
